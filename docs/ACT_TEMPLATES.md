# Автозаполнение актов

Формы основаны на предоставленных пользователем RTF «Акт приема-передачи материальных ценностей работнику» и «Акт при увольнении Работника». Исходные RTF не редактируются. Примерные сотрудники, техника и стоимость из образцов не заносятся в базу.

| Поле акта | Откуда берётся | Как уточнить |
|---|---|---|
| Компания | Настройки → Реквизиты актов | Вкладка «Реквизиты» нового акта |
| ФИО и должность представителя | Настройки → Реквизиты актов | Та же вкладка, кнопка «Запомнить реквизиты…» |
| Город / место | Настройки → Реквизиты актов | Та же вкладка |
| Основание | Настройки для выдачи/возврата/списания | Первая вкладка нового акта |
| Комиссия | Настройки → Реквизиты актов | Вкладка «Реквизиты» списания, по одному человеку на строку или через точку с запятой |
| Сотрудник, должность, отдел | Карточка сотрудника | При выдаче выбор сотрудника; при возврате — фактический владелец |
| Дата акта | Сегодняшняя локальная дата | Первая вкладка |
| Дата увольнения | Сегодняшняя дата, отдельно от даты акта | Форма «Возврат при увольнении» |
| Номер акта | Автоматически после проведения | Не вводится вручную |
| Техника, WIN, SN, характеристики, комплектность, состояние | Карточки выбранного имущества | Проверка на вкладке «Имущество»; изменения вносятся в карточки до проведения |
| Стоимость | Необязательное поле карточки имущества | Пусто → прочерк; 0 → 0,00; хранение в целых копейках |
| Единица / количество | шт. / 1 на каждый инвентарный объект | Несколько объектов → несколько строк |

Проведение атомарно сохраняет акт и его строки, меняет владельца/состояние имущества. Отмена формы до проведения не меняет имущество. Кнопка запоминания реквизитов сохраняет именно настройки сразу, независимо от последующей отмены формы. Отмена печати не отменяет проведённый акт.

Выдача и возврат печатаются с двумя сторонами и блоками подписей. Возврат при увольнении содержит отдельную дату увольнения. Списание содержит основание, заключение и подписи комиссии. Поля остаются редактируемыми до проведения; старые акты открываются из сохранённого снимка.

Печать доступна через «Просмотр / печать → Печать / PDF». Для PDF используется системный принтер Microsoft Print to PDF. Word и редактирование RTF для ежедневного оформления не требуются.
