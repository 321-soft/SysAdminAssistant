# Вход и персональные данные · 0.29.0

В окне подключения и повторного входа есть «Запомнить вход до закрытия приложения». По умолчанию галочка включена; её выбор сохраняется как предпочтение. Пароль и токен в connection.json не записываются.

С галочкой общие разделы работают без повторного ввода пароля, пока клиент остаётся подключённым. Фоновый запрос клиента поддерживает общий сеанс, даже когда окно свёрнуто в трей. Кратковременная потеря сети не требует пароля: клиент пытается восстановить соединение. После часа без подтверждённой связи (включая длительный сон компьютера) токен перестаёт действовать и требуется повторный вход. Показанная общая информация при отсутствии связи остаётся старым снимком, а не актуальными результатами.

Закрыть приложение означает «Выход» в трее; крестик может только скрыть окно в трей. После настоящего выхода и нового запуска нужен пароль. Токен существует только в памяти клиента. При штатном выходе выполняется короткая попытка отзыва на сервере; при аварийном завершении серверный токен истекает без обращений через час. При закрытии процесса клиент больше не может его использовать.

Если галочка выключена, сохраняется прежний общий сеанс с фиксированным сроком 8 часов. Его обычная активность не продлевает. После перезапуска службы сервера нужно снова войти — сеансы сервера не восстанавливаются с диска. Блокировка пользователя, изменение прав/пароля и выход отзывают доступ независимо от галочки. Переподключение не хранит и не подставляет пароль автоматически.

## Сотрудники и пароли

Общий вход не открывает персональные данные. «Инвентаризация» (сотрудники, выданное имущество и акты с ФИО) запрашивает отдельное подтверждение своего пароля на 5 минут. При уходе в другой раздел она закрывается; локальные строки инвентаризации удаляются из временной реплики. При истечении доступа открытый список закрывается после завершения работы с дочерним окном. Общие страницы по таймеру не перестраиваются. Перед новой загрузкой/операцией сервер всё равно проверяет разрешение и срок доступа.

Хранилище паролей использует независимую разблокировку на 5 минут, как прежде. Разблокировка сотрудников не открывает секреты и наоборот. Общий сеанс и его фоновое продление не продлевают эти 5 минут. Прежние правила просмотра/копирования секретов сохраняются.

В обычном снимке сервера нет сотрудников, имущества, актов и строк актов. Они возвращаются только по отдельному запросу разблокированной инвентаризации с правами на раздел. Это также относится к Excel сотрудников; шаблон без персональных данных доступен с правом чтения. Права разделов применяются дополнительно к разблокировке. Изменения служб, мониторинга, почты, счетов и устройств не требуют разблокировки персональных разделов.

Обновите сервер и клиент до 0.29.0. Агентов ради этого обновлять не нужно. Схема БД прежняя, сборка PUBLISH.bat. Проверки и ограничения — verification/AUDIT.md; визуальное поведение Windows и полный Windows NetworkSpecs здесь не запускались.
