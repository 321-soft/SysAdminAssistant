# Подробности проблем и рекомендации

Версия 0.31.2 добавляет пояснения в карточки проблем, окна агентов/журналов и новые уведомления Telegram. Подробности уже существующих проблем формируются при открытии карточки из сохранённых данных. Ранее отправленные сообщения Telegram не редактируются и не рассылаются повторно ради новых пояснений. Закреп остаётся компактной сводкой.

Для CPU, RAM, дисков, интерфейсов и служб показаны реальные значения из отчёта, порог, время и рекомендации. Для отсутствующей метрики не придумывается нулевое значение. Для журналов показаны правило, источник, ID, повторы, условия закрытия и исходные записи, если они сохранились. Источники и сведения, которых нет в отчёте, не восстанавливаются догадкой.

Все стандартные события Windows/Linux, стандартные правила журналов MikroTik, контроль API, чтения журналов и нестабильности интерфейсов имеют пояснения. Для пользовательских/неизвестных правил даётся общий порядок проверки и исходное сообщение. Существующие объяснения отчётов резервного копирования и аудита конфигурации сохранены.

Для /boot и /boot/efi показаны объём, свободное место и сработавшие условия. Если абсолютный порог не меньше всего раздела, сообщение указывает на неподходящую настройку. Порог ГиБ общий для устройства; его изменение затронет остальные тома. Само правило срабатывания в этой версии не менялось. Файлы ядра, загрузчика и другие данные автоматически не удаляются.

Рекомендации не являются автоматическим исправлением. Команды в сообщениях предназначены для просмотра. Изменения служб, файловых систем, firewall и пакетов следует выполнять только после проверки причины. В Telegram передаются факты и рекомендации без добавления полного сырого текста журнала; полный текст доступен в программе. Для проверок HTTP параметры URL и учётные данные не выводятся в пояснение.

Пояснения вычисляются сервером и клиентом по уже существующим отчётам. Для этой функции обнови сервер и клиент. Переустановка агентов не нужна; формат их подписанных отчётов не изменён.

Справочные материалы:
- systemctl: https://www.freedesktop.org/software/systemd/man/latest/systemctl.html
- journalctl: https://www.freedesktop.org/software/systemd/man/latest/journalctl.html
- Разбор неожиданных перезагрузок Windows: https://learn.microsoft.com/en-us/troubleshoot/windows-server/performance/troubleshoot-unexpected-reboots-system-event-logs

Рекомендации — ориентир для проверки, а не доказательство конкретной причины по одному событию.

В 0.32.0 Linux-данные расширены: дисковые пороги /boot больше не наследуют общий абсолютный минимум, inode и systemd контролируются отдельно. Рекомендации обновлены под фактические данные, детали — LINUX_UPDATE_0.32.md.
