# Единый Setup.exe для агента

В карточке устройства создаётся один EXE. Он содержит сжатый пакет с готовым агентом, мастером установки, серверной регистрацией и Microsoft .NET Desktop Runtime из локального хранилища. При отсутствии Runtime клиент спросит о загрузке в хранилище; последующие пакеты используют его повторно. Установщик Runtime уже сжат Microsoft, поэтому именно он определяет большую часть размера EXE. Конкретный размер показывается Windows после сохранения; обещания нескольких мегабайт нет.

При создании нет компиляции и запуска SDK. Маленькая оболочка собирается только при PUBLISH.bat системным компилятором .NET Framework Windows, код включён в packaging. .NET Framework 4.6.2 входит в Windows Server 2016; на более новых Windows используется совместимая системная версия. Это оболочка для установки, агент работает на .NET 10.

Запуск Setup.exe требует UAC. Каталог распаковки имеет случайное имя в ProgramData и разрешён только администраторам и SYSTEM. Перед распаковкой проверяется SHA-256 содержимого, все пути, дубликаты имён и пределы размеров; пути вне каталога, ADS и повреждённые данные отклоняются. После завершения мастера каталог удаляется. Runtime проверяется по SHA-512 и подписи Microsoft, существующий подходящий Runtime повторно не устанавливается. При требуемой перезагрузке показывается сообщение без принудительного рестарта.

SHA-256 внешнего контейнера защищает от случайной порчи, а не доказывает издателя. Внутренняя регистрация подписывается сервером и проверяется мастером, хеши агента сверяются с ней. Персональный EXE не имеет Authenticode-подписи Windows: Windows может показать неизвестного издателя. Не путай подпись регистрации с подписью EXE. Для публично доверенного подписанного EXE нужна отдельная подпись готового персонального файла сертификатом подписи кода; закрытый ключ не распространяется клиентам. Опциональная подпись опубликованных файлов агента сохраняется, оболочка-шаблон исключена, поскольку добавление персонального содержимого изменяет итоговый EXE.

Пакет регистрации остаётся временным секретом одного устройства. Не публикуй его; срок действия 24 часа. Подтверждение ключа агента на сервере обязательно.
