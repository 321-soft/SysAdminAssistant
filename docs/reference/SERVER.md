# Сервер 0.6
Для существующей 0.6 доступно обновление через GUI-установщик. Подробная последовательность — README.md и CLEAN_INSTALL.md.
Собери PUBLISH.bat на Windows, затем перенеси ServerSetup целиком. SETUP_SERVER.cmd устанавливает отдельные runtime-пакеты Microsoft при необходимости и запускает GUI.
Служба автоматически стартует вместе с Windows; обработка почты и мониторинг работают без открытого клиента.
HTTPS: локальный IP/DNS, настраиваемый порт (по умолчанию 7443), сертификат и проверка SHA-256 клиентом. Если порт занят, выбери свободный.
Firewall ограничивает доступ указанными LAN-подсетями; между подсетями должна быть маршрутизация.
Команда информации из PowerShell:
& "C:\Program Files\SysAdmin Assistant Server 0.6\SysAdminAssistant.Server.exe" --info --data-dir "C:\ProgramData\SysAdminAssistantServer-0.6"
Не публикуй API напрямую в Интернет.
Удаление — UNINSTALL_SERVER.cmd, отдельное подтверждение каждой базы. SETUP_SERVER.cmd автоматически открывает обновление при наличии службы.
