# Закреп активных проблем

Настройки → Telegram → «Закреплять список всех активных проблем». Функция включена по умолчанию. В закрепе критичные проблемы и предупреждения всех разделов, независимо от фильтров обычных уведомлений. Информационные записи и доступные обновления в закреп не попадают. Публикации MikroTik считаются группами. Игнорируемые и закрытые проблемы исключаются.

Обычно используется одно сообщение. Если список не помещается, создаются дополнительные страницы: проблемы не обрезаются молча. Сервер обновляет существующие страницы без звуковых уведомлений и снимает свой закреп с пустых страниц. Чужие закрепы не снимаются. ID сообщений сохраняются после перезапуска; если сообщение удалено, следующая попытка создаст замену.

В группах боту необходимо право can_pin_messages; в каналах — can_edit_messages. Ошибка прав не блокирует обычные уведомления. Статус закрепа доступен в настройках Telegram. При 429 учитывается retry_after. Смена чата тем же ботом снимает прежний управляемый закреп; при смене самого бота прежний закреп может потребоваться снять вручную. В случае сетевого обрыва в момент отправки Telegram не обеспечивает идемпотентность sendMessage: неподтверждённая отправка при повторе может оставить лишнее незакреплённое сообщение.

Обновление наблюдается примерно раз в 30 секунд плюс время запросов Telegram; это текущий список, а не гарантия доставки в реальном времени. При недоступном сервере или Telegram последнее сообщение может устареть. Обычная история событий сохраняется.
