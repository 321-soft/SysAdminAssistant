# Письма об обновлениях

1. В существующих словарях открой «Обновления». Встроенные DSM / QNAP получают типовые фразы один раз; правки пользователя не перезаписываются. Для своего продукта укажи название и буквальные фразы темы и/или тела.
2. В почтовом списке выбери письмо → «Привязать» → «Уведомление об обновлении». Выбери устройство и продукт. Для будущих писем добавь строки темы / тела с И/ИЛИ, посмотри предварительный просмотр и сохрани правило. По одному адресу отправителя автоматического назначения устройства нет.
3. У устройства появляется отдельный значок обновления. Наличие новой прошивки не меняет красный/жёлтый/зелёный статус и не создаёт задание бэкапа.
4. Нажми значок: видны продукт, версия, даты первого / последнего письма, исходное письмо и история. «Установлено» — ручное подтверждение фактической установки с записью пользователя и UTC-времени, без запуска обновления. Для чтения письма нужна роль «Отчёты», для подтверждения — редактирование соответствующего раздела устройств / коммутаторов.

DSM извлекается целиком, например `7.4.1-90080 Update 1`, включая суффикс Update. QTS / QuTS hero поддержаны типовыми шаблонами. Если версии нет или в письме несколько разных версий, не угадываем: отметка относится к тексту письма; посмотри источник вручную. Для произвольного формата версии может потребоваться расширение шаблона.

Одна версия одного продукта и устройства даёт одно предупреждение в общей очереди уведомлений Telegram с действующими фильтрами. Повтор не создаёт новую запись. После «Установлено» повтор той же версии не возвращает значок; другая версия создаёт новую запись. История подтверждений хранится с устройством и переживает удаление исходных писем по сроку хранения; исходное письмо после удаления открыть нельзя. Лимит истории — 1000 версий, превышение отправляет письмо на ручной разбор.

Письмо сообщает о доступности обновления, но не доказывает состояние NAS. Сведения прямого опроса ОС / RouterOS показываются отдельной вкладкой и имеют собственную актуальность. Настройки IMAP, допуск отправителей и проверка безопасности письма остаются прежними. Для этой возможности обнови сервер и клиент; агент на NAS не требуется.
