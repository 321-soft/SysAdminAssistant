# Словарь событий Kaspersky

Войдите в Assistant как главный администратор. Откройте **Kaspersky → Правила Kaspersky**. Кнопка **«Добавить типовые правила Kaspersky…»** покажет, какие правила будут добавлены. Это встроенный набор: скачивать отдельный файл не требуется. Подключение и уведомления настраиваются в разделе **Kaspersky**.

Типовой набор использует коды поля `event_type` из [справочника OpenAPI Kaspersky](https://support.kaspersky.com/help/KSC/15.3/KSCAPI/a00134.html): подозрительный объект, обнаружение вируса и неудачное лечение. Он не содержит адресов, имён хостов или идентификаторов устройств. Фактические события зависят от продуктов, их версий и политик журналирования. Для угроз используется ручное закрытие: лечение одного объекта на узле не подтверждает устранение другой угрозы.

На вкладке Kaspersky можно создать или изменить правило, выключить его, поменять уровень и разрешение Telegram. Проверяйте дополнительные коды по списку последних событий KSC. Если нужен файл для переноса, используйте **«Экспорт JSON…»** на вкладке Kaspersky. Экспорт включает правила и их переключатели без настроек подключения и паролей.

**«Импорт JSON…»** распознаёт файл автоматически: `Product: KSC` направляется в правила Kaspersky, а `Dictionaries` — в сетевые словари. Предпросмотр не сохраняет изменения. Правило с тем же ID заменяется после подтверждения; типовой набор добавляет только отсутствующие правила. Импорт действует на будущие события. Для Telegram одновременно включите уведомления в правиле и нужный уровень в разделе Kaspersky.

## KSC event dictionary

Open **Kaspersky → Kaspersky rules**. Add the built-in rules or use JSON import/export. The starter rules use documented OpenAPI event types without site-specific settings. The rules apply to new events; actual event availability depends on product and logging policy.
