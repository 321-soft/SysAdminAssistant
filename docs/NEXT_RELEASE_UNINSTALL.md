# Состояние согласованных доработок — 0.46.14

Реализовано в исходниках общего комплекта:

- Числовая и типизированная сортировка во всех таблицах, сохранение порядка при перечитывании и переходах, естественная сортировка имён.
- Стабильная верхняя панель со строкой действий над выделенными записями; фильтры и таблица не должны менять положение при выделении.
- Встроенные установленные деинсталляторы всех четырёх компонентов, общий Uninstall.exe внутри папки каждого компонента. Серверный GUI и Windows Apps используют установленный путь.
- Устранение исходных причин NU1510 и IL3000 без глобального подавления предупреждений.
- Самодостаточный Setup рабочих станций с вложенным MSI; автономный runtime установщика/удаления.
- RU/EN и переключение клиента/серверного окна без перезапуска, обновлённая лицензия и README с упором на почту, упорядоченный корень проекта.
- Сохранён проверенный пользователем сборщик оборудования 0.46.12.

Проверки и границы в [отчёте выпуска](../verification/RELEASE_0.46.14.md). Реальные Windows UI, WiX, установка и удаление требуют Windows. VERIFY.cmd включает проверки геометрии и сортировки; PUBLISH проверяет встраивание деинсталляторов.
