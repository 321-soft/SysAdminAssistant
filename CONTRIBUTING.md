# Contributing

Read LICENSE.txt before contributing. This project has custom source-available
terms; selling the Software or modified versions is restricted. Professional
services are permitted as specified in the license.

By submitting an original contribution for inclusion, you offer that contribution
under the same LICENSE.txt terms. You retain your copyright. You must have the
right to submit the contribution and identify any third-party material and its
license. No copyright assignment is requested.

Discuss substantial changes in an issue first. Keep each change focused, describe
the resulting behavior, and provide relevant verification. On Windows run
VERIFY.cmd and report any checks you could not perform. Do not claim a Windows
installation or UI was tested solely because a cross-build succeeded.

Never submit private keys, real configuration, employee data, passwords, tokens,
database files or unredacted customer logs. Use fictional fixtures.

Modified builds must be clearly identified and use their own publisher keys;
they must not be represented as official 321.su releases.
