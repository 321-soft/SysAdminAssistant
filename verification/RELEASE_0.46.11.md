# Проверка 0.46.11 — 23.11.2026

## Изменения

1. Перевод раздела рабочих станций дополнен по представленным экранам. Тест уже созданного окна переключает именно пункт «Рабочие станции».
2. KSC: ручное решение не является постоянным исключением. Новое событие с новым ID создаёт новую проблему; повтор старого ID не создаёт дубль. Подбор RDP и файловая угроза обрабатываются раздельно. Блокировка IP закрывает только связанную атаку; новая попытка снова учитывается. Полностью подтверждённые RDP-группы можно уточнить и в решённой истории.
3. Добавлено определение ответа OpenAPI с исключённой правой границей диапазона. При неподтверждённой/неполной странице позиция чтения сохраняется. Реальный ответ KSC из сети пользователя здесь недоступен: восстановление опроса требуется проверить после обновления сервера.
4. В WMI-запросах необязательный контекст передаётся как Type.Missing. Реальная ошибка со скриншота возникает в ConnectServer ещё до получения периферии. Исправление маршалинга компилируется, но требует проверки на Windows.
5. Исправлен форм-фактор SMBIOS (коды отличаются от Win32_PhysicalMemory). Отсутствующие свойства модулей подписаны, а не выведены отдельным «Не получено».
6. Default string/To Be Filled By O.E.M. не используются как S/N. Общий номер ПК и номер материнской платы разделены. Для сборного ПК общий заводской S/N не выдумывается. Существующий действительный серийник имущества не стирается из-за отсутствующих данных мониторинга.

## Проверки

- Полный набор Specs: 2061 проверка завершилась успешно.
- Desktop, Agent, Server, ServerSetup, AgentSetup, Uninstall и WindowsUiSpecs компилируются без ошибок и предупреждений.
- Windows UI и реальный COM/WMI здесь не запускались. Для отдельной проверки WMI на Windows:

```bat
dotnet run --project tests\SysAdminAssistant.WindowsUiSpecs -- --hardware-smoke
```

- Перед распространением требуется PUBLISH.bat и проверка установщиков на Windows. Архив содержит исходники.

## Что обновить

Сервер — KSC и обработка сведений имущества; клиент — перевод и подписи; агенты устройств и рабочих станций — WMI, DIMM/SO-DIMM и номера компонентов. Изменение форм-фактора в старых сохранённых отчётах автоматически не выдумывается: нужны новые данные агента.

## Документация интерфейсов

- Microsoft SWbemLocator.ConnectServer: https://learn.microsoft.com/en-us/windows/win32/wmisdk/swbemlocator-connectserver — необязательный контекст подключения.
- DMTF SMBIOS 3.9, таблица 76: https://www.dmtf.org/sites/default/files/standards/documents/DSP0134_3.9.0.pdf — DIMM 09h, SODIMM 0Dh.
- KSC EventProcessing.GetRecordRange: https://support.kaspersky.com/help/KSC/15.3/KSCAPI/a00526_a519ff2c395fd84b7eb46f6e4a93c2c92.html — параметры диапазона. Совместимость с исключённой границей проверена модельным ответом, а не на реальном KSC пользователя.
