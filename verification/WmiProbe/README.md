# Проверка сбора оборудования 0.46.14

На Windows с установленным .NET 10 x64 запустите RUN.cmd. Исходники утилиты — tests/SysAdminAssistant.HardwareProbe. Она использует те же NativeWmi и StationPeripheralCollector, что агент 0.46.14.

Проверка читает название ОС, характеристики и периферию. Служба агента, её регистрация, ключи и настройки не изменяются. Результат записывается локально в hardware-probe.txt. Файл содержит модели и серийные номера оборудования; автоматически он никуда не отправляется. Запуск от пользователя проверяет его контекст доступа, а не контекст службы LocalSystem.

Это диагностическая утилита, не установщик. Она не заменяет обновление агента и не требует обновления сервера. В этой среде выполнена компиляция; реальный запуск WMI требуется на Windows.
