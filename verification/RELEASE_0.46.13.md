# Проверка единого выпуска 0.46.13

Дата: 23.11.2026. Все четыре ранее согласованных пункта реализованы в одном исходном комплекте вместе со сборщиком 0.46.12.

## Реализовано

1. Общая сортировка DataGrid: исходные ключи рабочих станций и типизированное сравнение чисел, длительностей, размеров, дат, версий, IP; естественный порядок имён. Состояние сортировки сохраняется при обновлении и переходах. Отсутствующие значения остаются внизу в обоих направлениях.
2. Общая верхняя панель списков: строка действий для выбранных записей находится внутри панели. Высота зарезервирована, скрытие/отключение отдельных действий не схлопывает место. Узкое окно использует горизонтальную прокрутку строки.
3. Uninstall.exe включён в установочные пакеты и размещается в папках установленных сервера, клиента, агента устройств и агента рабочих станций. Серверный GUI и Windows Apps используют установленный путь. Для MSI регистрация Windows Apps ведёт в графическое удаление. При удалении программа запускает временную копию для освобождения своего каталога.
4. Нет прямого PackageReference ProtectedData в Uninstall (причина NU1510); нет Assembly.Location (причина IL3000). Варианты временного копирования выбираются условием сборки SAA_SINGLE_FILE, без глобального подавления предупреждений.

Графический Setup рабочих станций содержит MSI внутри. Самостоятельный MSI остаётся для GPO/KSC. Установщик и деинсталлятор рабочих станций собираются автономно с включённым runtime; это позволяет запускать их на ПК без глобального .NET. Клиент, сервер и агент устройств используют runtime своих установленных компонентов.

PUBLISH проверяет содержимое готовых клиентского/серверного Setup.exe, подпакетов агентов, наличие и размер Uninstall.exe в реальной MSI-таблице File; проверяет предел 200 МиБ MSI для совместимости с обновлением старых агентов. Сборочные каталоги Uninstall и WorkstationTools удаляются из итогового выпуска после проверки.

## Выполнено здесь

- 2099 спецификаций прошли, включая 11 < 20, 9 < 50, 9 дней < 50 дней, смешанные единицы, 7.9 < 7.25, IP, естественные имена и упаковку MSI внутрь Setup без соседних файлов.
- Агент, сервер, клиент, AgentSetup, ServerSetup, Uninstall, ProductMaintenance, UpdateProbe и WindowsUiSpecs компилируются без ошибок и предупреждений в доступном Linux SDK.
- Отдельно скомпилирована ветка Uninstall с SAA_SINGLE_FILE. Она не обращается к Assembly.Location.
- Сверена неизменность NativeWmi.cs и StationPeripheralCollector.cs со сборкой 0.46.12, которую пользователь проверил на Windows.
- Проверены локальные ссылки README, XML проектов/WiX, относительные пути упаковки и порядок включения деинсталляторов.

## Требует Windows

WindowsUiSpecs расширен: сортировка по клику, обратный порядок, сохранение выбранной записи, восстановление после обновления и координата таблицы при выборе/снятии/множественном выборе, ширины 390/800, RU/EN. Тест включён в VERIFY.cmd, но здесь не запускался: WPF/WinForms недоступны в Linux.

Полный PUBLISH.bat, реальная сборка self-contained win-x64, WiX, проверка VerifyInstallerContents.ps1 и установка/удаление на Windows здесь не выполнялись. При превышении установленного лимита или неполном пакете PUBLISH остановится, а не объявит выпуск готовым.

Архив — исходники и проверочная утилита, не готовые Windows Setup.exe. Для получения установщиков используется PUBLISH.bat на Windows.
