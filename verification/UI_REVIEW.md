# UI 0.26.0

Общие шаблоны полей ввода/паролей, выпадающих списков (включая редактируемые), пунктов и галочек; общая группировка действий форм и перенос footer. Информационные карточки теперь могут состоять из Section/Fact без большого поля ввода. Сертификат сервера и помощь агента переведены на такие карточки. Все значения остаются копируемыми, SHA-256 также имеет отдельную кнопку. Ошибка продления/следующий сертификат появляются только при наличии.

Проверено компиляцией, не WPF-исполнением. На Windows проверить основные страницы и вложенные формы: устройства/агент/роли/пороги, резервное копирование/письма/привязка, сеть/MikroTik/правила, счета/история, инвентаризация/акты, пароль/показать/копировать, настройки/сертификат/Telegram/watchdog, вход/переподключение. Особое внимание редактируемым ComboBox и фокусу. Системные диалоги Windows не подменяются.
