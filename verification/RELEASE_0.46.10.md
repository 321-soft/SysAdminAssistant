# Проверка выпуска 0.46.10

Дата: 23.11.2026. Среда проверки: Linux, .NET SDK 10. Исходный комплект предназначен для сборки Windows x64 через PUBLISH.bat.

## Выполнено

- 2049 основных спецификаций завершились успешно, включая отсутствие событий обновления BIOS и скрытие прежних записей BIOS в истории устройства и связанного имущества без удаления сохранённого журнала.
- Desktop, ServerSetup, AgentSetup, Server, Agent, ProductMaintenance, UpdateProbe и Uninstall скомпилированы без предупреждений и ошибок.
- Linux-агент скомпилирован без apphost: пакет apphost 10.0.14 отсутствует в локальном офлайн-кэше. Версия для публикации не понижалась.
- WindowsUiSpecs и NetworkSpecs скомпилированы без предупреждений и ошибок.
- Серверный тест через отдельную исполняемую оболочку: запуск на прежней схеме 7 восстанавливает недостающие поля, открытие инвентаризации и повторный запуск успешны; существующие карточки сохраняются. Реальный снимок мониторинга заменяет ошибочные характеристики, сохраняет учётные сведения, отвязка прекращает синхронизацию, удаление неиспользуемого имущества не удаляет станцию.
- Проверены пути ресурсов проектов, локальные ссылки README, единственный корневой PUBLISH.bat, перенос вспомогательных скриптов и включение исходников всех новых проектов в решение. PowerShell-файлы сохранены UTF-8 с BOM для Windows PowerShell 5.1.
- Проверка исходных src/docs/examples не обнаружила упомянутых в переписке корпоративных имён, адреса сервера, приватных ключей и действующих конфигураций подключения.

## Требует Windows

- Запуск WindowsUiSpecs с реальными WPF/WinForms окнами, включая переключение уже созданных кнопок управления службой в обе стороны. Тест включён в VERIFY.cmd.
- Полный NetworkSpecs с Windows-службами, DPAPI, ACL и HTTPS.
- Выполнение PUBLISH.bat: компилятор .NET Framework для оболочек, WiX, упаковка single-file и MSI, проверка размера подписанного агентского пакета.
- Чистая установка, обновление и удаление каждого компонента в RU/EN; проверка записей Windows Installed Apps, сохранения данных и отдельного удаления тестовой базы. SQL Server на Windows в этой среде не запускался.
- Сценарий общего MSI через GPO/KSC и графической оболочки на компьютере с .NET Desktop Runtime 10 x64. Прямой MSI служебного агента автономный, но графические утилиты требуют Desktop Runtime.

Архив содержит исходники и сценарии сборки, а не уже проверенные на Windows готовые Setup.exe. Запуск PUBLISH.bat на Windows обязателен для получения установочных пакетов.
