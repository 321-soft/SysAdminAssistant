# Проверка 0.46.9

Сборки Server, Desktop, Agent и ServerSetup: успешно, без предупреждений и ошибок.
Основной набор: 2036 проверок успешно. Проверяются физическая память, SMBIOS, история компонентов, серийные номера, неполные опросы, повторная отправка снимка, сохранение ожидающего подтверждения после перезапуска и история после отвязки имущества.
Серверный интеграционный тест: реальный ServerState обновляет существующую SQLite схему, повторный запуск и снимок после разблокировки инвентаризации успешны; синхронизация заменяет ошибочные характеристики, сохраняет учётные поля и прекращается после отвязки.

В среде Linux не проверены: фактические WMI/SMBIOS на Windows, периферия конкретных рабочих станций, визуальное поведение WPF, установка MSI и обновление через Kaspersky/GPO. Исправление COM-вызовов требует проверки на рабочей станции, где воспроизводилась ошибка.

Обновить сервер и клиент; для новых аппаратных сведений требуется агент 0.46.9. История начинается с первого полученного снимка этой версии. Время в истории — время обнаружения сервером, не точное время физической замены.
